===============================================================================
CSCI480 LAYERED IDS/IPS - LIVE DEMO
===============================================================================

START THE APP
--------------
1. Right-click run_demo.bat
2. Select "Run as Administrator"
3. Dashboard opens at http://127.0.0.1:5000

DEMO STEPS (5 minutes)
----------------------
1. Start capture on your network interface
2. Show results table filling with traffic
3. Click Model Settings - show 7 ML models
4. Click Defense & Prevention - show decoys and firewall
5. Deploy a decoy (fake_ssh)
6. Stop capture

ATTACK SIMULATION (optional)
-----------------------------
1. Install nmap from downloads/nmap-setup.exe
2. Run: nmap -sS 127.0.0.1
3. Watch system detect the scan

TROUBLESHOOTING
---------------
- Models unavailable? Check ML folder exists
- Capture failed? Run as Administrator
- No traffic? Select active network interface
