TROUBLESHOOTING
===============================================================================

Issue: "Models unavailable" error
Solution: Check that ML model artifacts exist in the ML folder

Issue: "Capture failed" error
Solution: Run as Administrator and ensure Npcap is installed

Issue: No traffic appearing
Solution: Select an active network interface with traffic (not a disconnected one)

Issue: Firewall blocking not working
Solution: Must run as Administrator for prevention/healing features

Issue: Port already in use
Solution: Stop any other applications using port 5000
