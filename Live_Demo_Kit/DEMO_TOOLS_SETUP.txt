DOWNLOADED TOOLS (in downloads/ folder):
----------------------------------------
1. nmap-setup.exe - Port scanning tool
   Install: Run nmap-setup.exe
   Use: nmap -sS 127.0.0.1
   Note: Includes nping for packet generation (similar to hping3)

2. packet_builder.exe - Colasoft Capsa Free
   Install: Run packet_builder.exe
   Use: Packet generation and analysis tool

3. hping3.zip - DoS tool (source code only)
   Note: Compiling on Windows requires C compiler + WinPcap - NOT feasible for automatic setup
   Alternative: Use nping (included with nmap)
